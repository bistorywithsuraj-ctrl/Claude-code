SRT एक साधारण text file है जिसमें subtitles और उनका समय होता है। YouTube, Premiere, CapCut और VLC, सब इसे पढ़ लेते हैं।

तरीका 1: AI से अपने आप

  1. Auto Captions में video डालिए और Hindi चुनिए।
  2. Text check कीजिए, फिर SRT download कीजिए।

तरीका 2: हाथ से लिखकर या ठीक करके

  1. SRT Subtitles खोलिए और video के साथ लाइन-दर-लाइन subtitles लिखिए या पुरानी SRT खोलिए।
  2. समय आगे-पीछे कीजिए, गलतियाँ ठीक कीजिए।
  3. नई SRT file save कीजिए।

YouTube पर लगाना

YouTube Studio → Subtitles → भाषा चुनिए → Upload file → "With timing" → अपनी SRT।
