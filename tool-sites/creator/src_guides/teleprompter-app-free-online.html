Camera के सामने लाइन भूल जाना सबसे आम परेशानी है। Teleprompter पर script धीरे-धीरे ऊपर चलती है और आप camera की तरफ़ देखते हुए आराम से बोलते हैं।

तरीका

  1. पहले Script Timer से देखिए कि script कितनी लंबी बनेगी।
  2. Teleprompter खोलिए और script paste कीजिए। हिंदी भी चलती है।
  3. Speed और अक्षरों का size सेट कीजिए।
  4. Screen को camera lens के ठीक नीचे रखिए और Start दबाइए।

Tips

  • Text की चौड़ाई कम रखिए ताकि आँखें ज़्यादा न घूमें।
  • Speed अपनी बोलने की रफ़्तार से थोड़ी धीमी रखिए।
  • Script बोलचाल की भाषा में लिखिए, किताबी नहीं।
