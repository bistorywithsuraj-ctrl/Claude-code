# I'm Open: music video

The video is made in code. `mv.html` draws every frame on a canvas as a function of song time. `render.py` opens it in a headless browser, captures each frame and encodes it with ffmpeg.

## Files
- `mv.html`: all scenes, the lyric engine and the 3D letter tiles
- `data.js`: lyric word timings and the song's loudness and beat data (generated by `prep.py`)
- `prep.py`: rebuilds `data.js` from `lyrics_large-v3-turbo.json` and `song.mp3`
- `render.py`: renders stills or the video
- `fonts/`: the fonts used in the video
- `song.mp3`: **not included**. Copy your own "I'm Open" MP3 into this folder with this exact name.

## One-time setup (Mac)
```bash
brew install ffmpeg python
pip3 install playwright numpy
python3 -m playwright install chromium
```

## Preview and render
```bash
cd music-video/im-open
python3 -m http.server 8781 &                     # serves the page to the renderer
open "http://localhost:8781/mv.html?t=64"         # view one moment in your browser (t = seconds)
python3 render.py stills 12 64 120 185            # save test frames into st/
FPS=30 python3 render.py video 4                  # full song, 4 parallel browsers -> silent.mp4
FPS=30 python3 render.py video 4 57 88            # only 0:57-1:28 (first chorus)
ffmpeg -i silent.mp4 -ss 57 -t 31 -i song.mp3 -map 0:v -map 1:a -c:v copy -c:a aac -shortest clip.mp4
```
For the full song, use `-i song.mp3` without `-ss`/`-t` in the last step.
